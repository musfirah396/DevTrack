# 🚀 DevTrack

DevTrack is a simple and responsive **developer productivity and task-tracking app** built using **HTML, CSS, and JavaScript**. It provides a clean interface for developers to organize tasks, track progress, and manage their daily development workflow.

## ✨ Features

* 📋 Create and manage development tasks
* ✅ Track completed and pending tasks
* 📊 Monitor development progress
* 💻 Clean and responsive user interface
* ⚡ Fast and lightweight
* 📱 Works across desktop and mobile devices
* 🎨 Modern UI built with pure CSS
* 🔧 Developed using vanilla JavaScript

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and interactivity

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/devtrack.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd devtrack
```

### 3. Run the app

Simply open `index.html` in your browser.

No additional dependencies or installation are required.

## 🎯 Purpose

DevTrack was created to provide developers with a simple way to organize their work and keep track of their development tasks without relying on complex productivity tools.
